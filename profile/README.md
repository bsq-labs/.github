## Conditional Compilation Toolkit

AOT conditional compilation for the mainstream front-end source types (XML / CSS / JS). Comment directives act as compile-time instructions to precisely trim source per target platform — reducing bundle size and runtime overhead. Useful for memory / performance optimization and as the build-side of multi-platform / cross-platform / cross-end solutions.

- **JS** — [babel-plugin-conditional-compile-with-comment](https://www.npmjs.com/package/babel-plugin-conditional-compile-with-comment)
- **CSS** — [postcss-plugin-conditional-compile](https://www.npmjs.com/package/postcss-plugin-conditional-compile)
- **XML / templates** — [xml-conditional-compile](https://www.npmjs.com/package/xml-conditional-compile)
